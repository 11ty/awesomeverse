Sign in to the fa command-line tool from your browser, with no tokens to copy and paste.

It uses the OAuth 2.0 device flow, so your clipboard gets the day off. See the [Font Awesome packages docs](https://fontawesome.com/docs/web/setup/packages) to get set up.

The icon detail page picked up a batch of new animations, including flip, buzz, float, jello, swing, and wag (tail not included). There are also new padding controls for square and roomy canvases, because even icons appreciate a little personal space. Every option applies live to the preview and drops straight into your code snippet. Try them from any icon in [icon search](https://fontawesome.com/search).

Icon requests now live in GitHub Discussions, and the Icon Leaderboard ranks them by upvotes.

Want an icon we don't have yet? Upvote it on the [Icon Leaderboard](https://fontawesome.com/leaderboard), and the most wanted icons rise to the top. The request FAQs moved there too, so the answers sit right next to the votes. Democracy, but for icons.

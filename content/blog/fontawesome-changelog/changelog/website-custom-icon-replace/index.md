Swap a custom icon's SVG in place, keeping its name and every reference to it.

Need to update a custom icon? Pull a Freaky Friday and swap its SVG in place. Same name, same references, and your live sites never notice the switch. No more delete-and-re-upload dance. Learn more about [working with custom icons](https://fontawesome.com/docs/web/add-icons/upload-icons).

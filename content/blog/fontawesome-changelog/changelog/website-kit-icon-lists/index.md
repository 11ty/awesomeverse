Kits with hand-picked icons get Export list and Import list links on the Icons tab, and up to 5,000 icons can be imported in a single save.

Export and import your Kit's icons right from the Icons tab. No more digging through settings.

-   **Import up to 5,000 icons at one time.** Drop in a Kit export zip or any mix of .csv and .txt files. No more unzipping and importing one style at a time.

Lists from older exports still work. See [Kit icon lists](https://fontawesome.com/docs/web/setup/kit-icon-lists) for the details, or head to [your Kits](https://fontawesome.com/kits) to try it. Moving icons around has never been so list-less.

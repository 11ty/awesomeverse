Rebuild a Kit's package yourself from its Package view, instead of asking Support.

If your Kit's package looks stale or broken, rebuild it yourself from the Kit's Package view. It's the digital equivalent of turning it off and on again, and you no longer need to ask us to do it for you. Find it in [your Kits](https://fontawesome.com/kits).

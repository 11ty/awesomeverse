Collect icons in a tray while you browse search, then add them all to a Kit in one go.

See an icon you like? Hit the plus button to toss it in the tray and keep browsing. Gotta catch 'em all? Now you actually can. Try it from [icon search](https://fontawesome.com/search) or any icon category page.

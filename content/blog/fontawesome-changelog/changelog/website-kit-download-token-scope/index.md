A new Kit downloads scope lets API tokens download your Kits, so builds and scripts can fetch them without you.

API tokens can now include a Kit downloads scope, so your build pipeline or deploy script can grab a Kit on its own. Robots love a download link. Set it up from the [Tokens tab](https://fontawesome.com/account/tokens) in your account.

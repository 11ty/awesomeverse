Bringing an existing icon list to a Kit used to mean adding icons one at a time. Now hit Import Icons on [your Kit](https://fontawesome.com/kits), paste the list (one name per line, and don't sweat stray `fa-` prefixes or quotes), preview the matches, fix any typos we flag, and add the whole batch in one go. One paste instead of 750 clicks. Your mouse thanks you.

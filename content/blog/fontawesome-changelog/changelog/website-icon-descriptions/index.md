Icon pages now describe what each icon shows, brand icons included.

Every icon page now has a short description of what the icon shows, just below its tags. Brand icons got theirs too. Handy when you're choosing between two lookalikes, or writing alt text. Browse them in [icon search](https://fontawesome.com/search).
